🌹 Roses Are Red 💕

A Beautiful Valentine's Day Web Experience

📖 About This Project

"Roses Are Red" is an elegant, interactive web application designed for Valentine's Day. It takes your loved one on a romantic journey through seven days of Valentine's week, culminating in "The Question" - a playful yet heartfelt proposal with an interactive NO button that cleverly evades the cursor.

✨ Key Features

🎭 Ancient English Aesthetic

Jane Austen & Pride and Prejudice inspired design with elegant typography and sophisticated color schemes.

🎵 Taylor Swift Ambiance

Slowed, atmospheric background music creates a romantic mood throughout the journey.

🌹 7 Days of Romance

Each day celebrates a different aspect: Chocolate Day, Rose Day, Propose Day, Teddy Day, Promise Day, Kiss Day, and Valentine's Day.

🎪 Interactive "NO" Button

The NO button playfully runs away from the cursor, creating a humorous yet charming interaction.

🎨 High-End Design

Premium UI using Tailwind CSS with glass-morphism effects, animations, and particle systems.

✨ Smooth Animations

Falling roses, floating hearts, confetti bursts, and glowing text create magical visual moments.

🚀 How to Use

  1. Open the Project: Open index.html in your web browser or use a local server.
  2. Start the Journey: Click "Begin My Journey" to start the romantic experience.
  3. Enjoy Each Day: Navigate through all 7 days of Valentine's week.
  4. The Big Question: On Day 7, you'll see "Will you be my Valentine?" with YES and NO buttons.
  5. Play with the NO Button: Try to click it - it will cleverly run away!
  6. Click YES: Watch the final celebration with confetti and heartfelt messages.
💡 Pro Tip: For the best experience, enable sound/music by clicking the music button on the landing page!

🎨 Design Elements

  • Color Palette: Deep purples, rose pinks, gold accents, and elegant gradients
  • Typography: Playfair Display (headings), Cormorant Garamond (body text)
  • Custom Cursor: Beautiful custom cursor throughout the experience
  • Animations: Smooth transitions, floating elements, glowing effects
  • Glass Morphism: Modern frosted glass effect for cards and containers

🎵 Music

The application features slowed-down, atmospheric music perfect for a romantic mood. The music plays on loop in the background and can be toggled on/off using the music button on the landing page.

🌐 Running Locally

Option 1: Direct Browser

Simply open index.html in your web browser. All files are self-contained with no external dependencies required.

Option 2: Local Server (Recommended)

For the best experience, run a local server:

Python 3:

python -m http.server 8000

Python 2:

python -m SimpleHTTPServer 8000

Node.js (with http-server):

npx http-server

Using Live Server (VS Code):

Install the Live Server extension in VS Code, then right-click index.html and select "Open with Live Server".

Then visit http://localhost:8000 in your browser.

🎯 The Running NO Button

The interactive NO button on day7.html is the crown jewel of this application. Here's how it works:

  • When the user tries to hover or click the NO button, it randomly repositions itself on the screen
  • After several attempts, frustration messages appear ("You're so close!", "Just click YES!")
  • The NO button becomes smaller and slightly transparent after multiple attempts
  • The YES button remains stationary and encouraging
  • This creates a playful, humorous, yet ultimately romantic interaction

🎁 Customization

You can easily customize this project:

  • Messages: Edit the romantic quotes and declarations
  • Animations: Adjust animation durations and styles
  • Music: Replace the audio source URL with your preferred music file
